# Contributing

Issues and pull requests are welcome. Please:

1. Open an issue describing the bug or proposal before large pull requests.
2. Add or update a test under tests/ for any behavior change; CI runs the
   Python 3.10-3.12 matrix on every push.
3. Add Apache License 2.0 headers to new source files.
4. Keep this repository's public research scope: AI security and data
   engineering content only.
5. Benchmark claims in documentation should state hardware, measurement
   method and repetition count so results are reproducible.
